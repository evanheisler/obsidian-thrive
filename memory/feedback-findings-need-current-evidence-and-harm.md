a harmless layering observation (route-registry importing the context module) —
"Irrelevant. You are just looking for issues" — and a pre-compaction "magic-link
signed-in gap" I could no longer evidence — "I don't know what this even means, so I
can't tell if you are inventing work here also." The third, a config-inferred defect,
was already disproven by then ([[feedback-no-negative-claims-from-bounded-queries]],
second instance).

**Why:** each raised finding spends Evan's attention and implies queued work. An item
without current evidence is indistinguishable from invention even when it was once
real; an item without harm-plus-action is an agent hunting for something to report.

**How to apply:** before raising anything, require BOTH: (1) evidence observed this
session — a command output or behavior I can paste; a finding carried across a
compaction is unverified again, so re-derive it or drop it silently; (2) a concrete
harm and an action it implies — smells, inventories, and "worth noting" observations
don't get raised at all. The halt report of a loop lists artifact states, not
discovered curiosities. Rule now lives in the work-project skill's halt section
(finding bar). Related: [[feedback-state-the-finding-then-ask]],
