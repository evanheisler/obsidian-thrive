2026-08-20 (Agent OS migration): I reported studio `identities.email` as "genuinely
undeterminable" twice instead of asking. Evan: "Why the fuck didn't you just ASK for the
goddamn email? its evan@heisler.studio."

**Why:** "Not determinable from any source I can read" excludes the cheapest source — Evan.
Parking a one-line personal fact as TBD trades a five-second question for a stale config.

**How to apply:** When a required fact is personal knowledge (emails, account names,
preferences) and no repo/config source holds it, ask Evan for it directly — as the turn's one
decidable item — instead of shipping a TBD. TBD is only for facts pending a later pipeline
stage by design. Related: [[feedback-environment-questions-go-to-human]].
